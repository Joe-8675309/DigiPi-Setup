# DigiPi-Setup
Applying personalized config to an initial DigiPi installation.
Tested on DigiPi:
- 2.2-1
- 2.3-Beta3

# Optional Components Modified
- Hotspot Disable
- Filesystem Read-Write
- Hostname Configuration (also written to the UI)
- APRS-IS / Internet Gateway
- Static IP (eth0)
- PAT Persistent Email

# Running the script
- wget https://raw.githubusercontent.com/Joe-8675309/DigiPi-Setup/refs/heads/main/setup.sh
- chmod +x setup.sh
- sudo ./setup.sh
